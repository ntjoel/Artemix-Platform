# Artemix-Platform
Quatis vision panel: HMI industriale, integrazione VisionPro, gestione indipendente delle camere, trigger, ricette e diagnostica.

Il progetto e la documentazione sono nella cartella [QtisVisionPanel](QtisVisionPanel/README.md).

Baseline sorgente: release 3.1.6.1, commit operativo `786ed5febf3cf6716260d618001436a6f8011f21`.

Questa pubblicazione contiene i sorgenti correnti e conserva il commit iniziale della repository GitHub. Binari, cache, pacchetti NuGet scaricati, configurazioni personali e storico operativo locale sono esclusi.

Prima di compilare, ripristinare i pacchetti NuGet e installare le dipendenze industriali richieste dal progetto, tra cui Cognex VisionPro e Advantech DAQNavi. Le librerie vendor non sono distribuite qui.

Per le credenziali da configurare e le differenze rispetto alla copia operativa, leggere [PUBLICATION.md](PUBLICATION.md).
